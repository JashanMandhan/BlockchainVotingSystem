# Blockchain-Based Voting System

A database-backed voting system designed with blockchain principles for tamper-evident vote recording. Includes a complete relational schema, ER diagram, and SQL implementation.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Database | SQL (relational schema) |
| Schema Design | ER Diagram, Schema Diagram |
| Concepts | Blockchain integrity, DBMS, normalisation |

## Project Structure

```
4_Blockchain_Voting/
├── Blockchain_voting.sql      # Full database schema and seed SQL
└── DBMS_Project/
    ├── ER Diagram.png          # Entity-Relationship diagram
    ├── ER Diagram Prototype.png
    ├── Schema Diagram.png      # Relational schema diagram
    └── Schema Diagram Prototype.png
```

## Database Schema Highlights

- Voter registration and authentication tables
- Candidate and election management
- Vote recording with hash-chain integrity fields
- Audit log tables for tamper detection
